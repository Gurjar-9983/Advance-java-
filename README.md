\# Advanced Java — Lab Experiments \& Major Project



This repository contains my Advanced Java lab experiments and major project submitted as part of my college coursework.



\## 📚 Lab Experiments



The `Lab-Experiments` folder contains the following programs:



1\. \*\*Student Registration\*\* — Java-based student registration application.

2\. \*\*Basic Calculator\*\* — Calculator implemented using the MVC pattern.

3\. \*\*Client-Server Programming\*\* — Communication using Java sockets.

4\. \*\*RMI Client-Server\*\* — Remote Method Invocation using Java.

5\. \*\*Servlets\*\* — Java Servlet and web programming examples.

6\. \*\*Student Registration with JDBC\*\* — Student registration and database connectivity using JDBC.



\## 🛒 Major Project: ShopSphere



ShopSphere is a Java-based web application project.



\*\*Technologies used:\*\*

\- Java

\- Maven

\- Jakarta Servlet/JSP

\- MySQL

\- Apache Tomcat

\- HTML and CSS



The project source code is located in `Major-Project/ShopSphere/web`.



\## ⚙️ Requirements



\- JDK compatible with the project's Maven configuration (Java 17 for ShopSphere)

\- Apache Maven

\- Apache Tomcat 11 for ShopSphere

\- MySQL Server

\- MySQL Connector/J



\## 🚀 Setup Notes



1\. Clone or download this repository.

2\. Configure MySQL and create the required database.

3\. Configure database credentials in the appropriate local configuration, such as Tomcat JNDI for ShopSphere.

4\. Build the Maven project from the relevant project directory.

5\. Deploy the generated web application to a compatible Tomcat server.



Refer to individual project instructions where available.



\*\*Security note:\*\* Database credentials and other secrets should be configured locally and must not be committed to GitHub.
