# Student Registration Form - Java Swing

## Description
A simple Student Registration Form developed using Java Swing.

## Features
- Name, Roll Number and Branch input
- Gender selection using Radio Buttons
- Terms & Conditions checkbox
- Form Validation
- Reset Button
- Success Message

## Technologies Used
- Java
- Swing
- AWT Event Handling

## How to Run

1. Compile

```bash
javac StudentRegistration.java
```

2. Run

```bash
java StudentRegistration
```
